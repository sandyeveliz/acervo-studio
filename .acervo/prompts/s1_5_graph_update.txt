You are a knowledge graph curator AND fact extractor. You have two jobs:
1. Clean and connect the graph after new entities were extracted from a conversation.
2. Extract any additional entities, relations, or facts from the assistant's response that were not already captured.

═══ NEWLY EXTRACTED ENTITIES (from user message) ═══
These were already extracted from the user's message. Do NOT re-extract them.

{new_entities}

═══ EXISTING GRAPH (relevant nodes) ═══
{existing_nodes}

═══ ASSISTANT RESPONSE (current turn) ═══
This is the assistant's response to the user. Extract any NEW entities, relations, or facts from this text that are NOT already in the newly extracted entities above.

{current_assistant_msg}

═══ TASK 1: GRAPH CURATION ═══

1. MERGES — Identify semantic duplicates (same real-world thing, different label).
   Only merge when you are CERTAIN they refer to the same thing.
   When merging, "from" is the id to remove, "into" is the id to keep.

2. NEW RELATIONS — Create connections between new and existing nodes that are STRONGLY implied by context.
   Rules:
   - Only PERSONAL→PERSONAL or PERSONAL→UNIVERSAL relations.
   - NEVER create UNIVERSAL→UNIVERSAL relations.
   - Use precise verb phrases. If not sure, skip.
   - Valid relations: part_of, created_by, maintains, works_at, member_of, uses_technology, depends_on, alternative_to, located_in, deployed_on, produces, serves, documented_in, participated_in, triggered_by, resulted_in

3. TYPE CORRECTIONS — Fix clearly wrong types.
   Valid types: person, organization, project, technology, place, event, document, concept

4. DISCARDS — Mark entities that should NOT exist (conversation topics, vague phrases, abstract categories, jargon like index names or SQL terms).

═══ TASK 2: ASSISTANT RESPONSE EXTRACTION ═══

Extract from assistant's response:
- New entities NOT already in the extracted list
- Facts stated by assistant (speaker: "assistant")
- Relations explicitly stated by assistant

Same rules: real named things only, precise verb phrases, PERSONAL only if user owns/uses it.

Return ONLY valid JSON:
